About NextGen Game Radar

What is NextGen Game Radar?

NextGen Game Radar is a free, open dashboard that displays upcoming video game releases and latest Metacritic review scores across PC, PlayStation 5, Xbox Series X/S, and Nintendo Switch. We provide gamers, journalists, and industry professionals with an at-a-glance view of what is coming next in gaming.

Features

  • Upcoming game releases organized by month
  • Metacritic score display with color-coded badges
  • Filter by platform: PC, PS5, Xbox Series X/S, Nintendo Switch
  • Filter by genre: Action, RPG, Adventure, and more
  • Sort by release date, score, or name
  • Available in 8 languages
  • Responsive design for all devices

Data Source

All game data is provided by the RAWG Video Games Database API, one of the largest video game databases with 800,000+ games. Metacritic scores are sourced through RAWG's aggregated data.
